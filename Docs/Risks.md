## 2. 已缓解风险详解

### R1 远程命令注入

`app/routes/servers.py` 在调用 SSH 前，对 `log_path` 使用
`re.fullmatch(r'/[A-Za-z0-9._/*-]+')` 且拒绝 `..`，对 `unit` 使用
`re.fullmatch(r'[A-Za-z0-9@._-]+')`，`lines` 强制为 1–10000 的整数。
校验通过后直接字符串拼接（不使用 `shlex.quote`），既堵住注入又保留 `*` 的 glob 语义。

### R2 鉴权

`app/main.py` 的 `admin_token_auth` 中间件是唯一鉴权入口：只拦截 `/api/*`，
用 `secrets.compare_digest` 做常量时间比较，豁免 `GET /api/health`、`/static/*`
与 9 条页面路由。`run.py` 在令牌为空时打印 WARN 并强制绑定回环地址。

### R5 命令策略

`_classify_command` 是确定性纯函数，任何 shell 元字符（含 `` ; & | ` $ ( ) < > { } ``
与换行）直接 400，杜绝前缀绕过；其余按首 token 白名单分「直接执行档」与「确认档」。

### R7 demo 隔离

`demo/reset` 显式按 `server_id IN (SELECT id FROM servers WHERE is_demo=1)`
删除三张子表，再删演示服务器本身，不单纯依赖外键级联，保证旧库残留也能清干净。

### R13 数据库迁移

`migrate_legacy_db` 顺序固定：目标已存在则跳过；否则对源库执行
`PRAGMA wal_checkpoint(TRUNCATE)` 后关闭，再对 `.db` / `-wal` / `-shm` 逐个
`os.replace`；任一步失败则反向回滚已移动文件并抛出，绝不留下半迁移状态。

## 3. 残余风险（接受或部分缓解）

### R17 SSH 主机密钥不校验

`ssh.py` 所有连接使用 `known_hosts=None`，不验证服务器主机密钥。
在 `127.0.0.1` / 内网可信环境中可接受，但若在不可信网络使用，存在中间人风险。
**建议**：公网或跨网段使用时改为加载 `known_hosts` 并启用严格校验。

### R18 供应商密钥明文

`providers.api_key` 在数据库中以明文存储，仅在 API 响应时脱敏。
**建议**：数据库文件依赖操作系统权限（`0600`）保护；如需更高安全等级，
应改为 Fernet 加密存储并在读取时解密。

### R20 演示数据时间戳缺口

`app/routes/demo.py` 中每个采样点计算了 `t`（时间）但 `save_health_check`
只使用自身的 `now()`，导致 144 个演示健康点的时间戳几乎相同，24h 趋势图失真。
这是 T11 遗留、T18 用 `per-file-ignores` 豁免的已知缺口，本次 T20 只记录不修。
**建议**：后续把时间戳参数下沉到 `save_health_check`。

### 未实现的中文/国际化

界面文案以中文为主，未做 i18n。对目标用户（中文运维/学生）可接受。

## 5. 安全假设

1. 应用默认只监听 `127.0.0.1`，不直接暴露公网。
2. `ADMIN_TOKEN` 通过 `.env` 注入，`.env` 不入库、权限受控。
3. 被管理的 SSH 服务器位于可信内网。
4. LLM 供应商可信，返回内容仍按不可信处理（已做转义）。
5. 数据库文件仅本机用户可读。

## 6. 监控与运维风险

- **密钥漂移**：`SSH_ENCRYPTION_KEY` 丢失将导致已存密码无法解密。
  建议备份 `.env` 中的该键。
- **数据库体积**：`health_checks` 与 `execution_logs` 每日清理 30 天前数据；
  若清理任务失败，文件会持续增大。
- **调度重叠**：已用 `max_instances=1` 防重叠，但单次检查超时 30s；
  若服务器数量很大，每分钟扫描可能积压，需观察。
- **Webhook 失败**：发送失败只打印 stderr，不重试、不阻塞告警落库。

## 7. 风险应对原则

1. **安全优先**：涉及命令执行与鉴权的改动必须先过失败用例。
2. **失败即降级**：SSH / LLM 不可用时不影响数据落库与页面可用。
3. **可回滚**：数据迁移与安全策略改动都设计为可逆。
4. **可测试**：核心安全逻辑（命令分类、路径校验）保持纯函数，便于回归锁定。
5. **文档同步**：任何行为变更都必须同步更新 README 与 Docs。
